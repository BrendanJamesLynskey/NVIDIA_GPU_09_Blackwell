# Blackwell — Dual-Die, FP4, and the NVL72 Rack-Scale GPU

A deep dive into NVIDIA's Blackwell architecture: the dual-die B200 package with the 10 TB/s NV-HBI link, 5th-generation tensor cores with MX-FP4 microscaling, the 2nd-generation Transformer Engine, the RAS engine and decompression engine, NVLink 5 at 1.8 TB/s per GPU, the GB200 Grace-Blackwell superchip, and the NVL72 rack-scale superpod. Includes an interactive throughput planner.

**Live site:** https://brendanjameslynskey.github.io/NVIDIA_GPU_09_Blackwell/

Part of the [NVIDIA GPU Architectures series](https://github.com/BrendanJamesLynskey/LLMs#nvidia-gpu-architectures).
